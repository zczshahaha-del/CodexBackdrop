Codex 动态背景 3.5.4

使用方法
1. 把“Codex 动态背景.app”拖进“应用程序”，然后双击启动。
2. 点击屏幕顶部菜单栏中的星光图标。
3. 选择内置动态效果，也可以选择自己的照片或视频。
4. 连接已开启时立即应用；连接未开启时先弹出确认。点“重新启动并应用”才会退出、重新打开 Codex 并应用背景，点“取消”保留选择且不退出。
5. 在菜单内拖动“背景可见度”滑杆：数值越高，背景越清晰。
6. 勾选“背景始终清晰”后，滑杆只改变界面透明度，照片和视频不会随之变暗或变模糊。
7. Codex 重启或更新后背景消失，点击“重新应用背景”，助手会检查连接，必要时先请求重启确认。

内置效果
- 流动渐变（轻量，默认推荐）：蓝紫、青色和玫瑰色柔和流动。
- 极光（轻量）：绿青色与蓝紫色光带缓慢摆动。
- 柔光光斑（轻量）：暖色和蓝色光斑缓慢漂浮。
- 流星雨（轻量）：静态星空上偶尔划过流星。
- 四种轻量效果只动画移动和透明度，不逐帧重绘整屏；窗口不可见时暂停，支持系统减少动态效果设置。
- 宇宙星河：缓慢流动的星云与纵深星轨，实时绘制开销较大。
- 动态粒子：蓝紫色漂浮粒子与动态连线。
- 所有效果都在本机生成，不需要下载视频，也不会联网。
- 2.1 已移除输入框下方的系统黑色渐变遮罩。

照片和视频
- 照片支持 PNG、JPEG、WebP、GIF、HEIC 和 HEIF，最大 80 MB。
- 视频支持 MP4、MOV、M4V 和 WebM，最大 200 MB。
- 文件只在本机内存中加载，不会上传。

建议
- 使用 10–30 秒、无声音、可循环的视频。
- 建议视频小于 100 MB；硬限制为 200 MB。
- 默认情况下，“背景可见度”会同时调整面板透明度、磨砂模糊和照片/视频亮度。
- 开启“背景始终清晰”后，照片和视频的亮度、饱和度及清晰度固定不变。
- 滑杆数值和清晰模式都会保存在本机。
- 后台恢复或应用背景时仍可调整滑杆；完成后会应用最后选定的透明度。
- 3.4 适配新版 Codex 的聊天面板和侧边栏，移除挡住背景的固定深色底层。
- 粒子与星轨位于界面后面，不会覆盖文字和按钮。

注意
- 这是本地非官方增强，不会修改 ChatGPT.app 安装文件。
- 助手运行时，Codex 已开启背景连接的情况下，重启或页面重新加载后会自动恢复当前背景。
- 运行中连接未开启时，助手保留最后选择；连接恢复后自动应用，等待期间关闭背景会取消待应用选择。
- Codex 未运行时，选择背景会正常打开它。已运行但缺连接时，只有你点击“重新启动并应用”才会请求正常退出；退出未完成时不会强制退出或打开第二实例。
- 自动恢复不会弹重启确认，也不会退出 Codex。重启确认会明确提示其他聊天将受中断。
- 主动关闭背景后，不会自动重新启用。
- ChatGPT 大版本更新后，界面类名可能变化，届时需要更新助手。
