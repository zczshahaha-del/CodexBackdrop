# 增加“背景始终清晰”选择

## 需求

用户希望保留两种调节方式：

- 联动模式：滑杆同时改变界面遮罩、毛玻璃和背景亮度。
- 始终清晰：照片或视频本身不随滑杆变暗、变模糊，滑杆只调整界面遮罩。

## 验收条件

- 菜单栏提供可保存的“背景始终清晰”开关。
- 开启后，无论滑杆位于 10% 还是 100%，背景滤镜和毛玻璃参数保持一致。
- 关闭后，保留 3.1 的联动行为。
- 切换开关后立即生效，不需要重新选择照片或视频。

## 验收结果

- 3.2.0 菜单包含可保存的“背景始终清晰”开关。
- 照片与视频分别在 25% 和 85% 下验证：背景滤镜均保持 `brightness(1.1) saturate(1.12)`，毛玻璃均为 `blur(0px)`。
- 关闭开关后，25% 下恢复为 `blur(13.5px)` 和 `brightness(0.86)`，确认联动模式保留。
- 切换只更新现有页面参数，不会重新读取照片或视频。
