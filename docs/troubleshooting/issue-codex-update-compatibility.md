# Codex 更新后背景失效

## 环境与现象

- 2026-10-08，Codex 26.1002.52244（13536），背景助手 3.2。
- 助手正常运行，已保存粒子模式和清晰开关，但本机 9224 连接不存在。
- 更新后的正常启动未携带背景所需的远程调试参数。

## 修复

- 重新启动时显式指定现有 Codex 用户目录和本机调试参数，保留已有登录与设置。
- 支持 ChatGPT.app、Codex.app 和当前运行应用的安装路径。
- 菜单明确提供“重新应用／修复连接”，连接未开启时显示对应状态。
- 连接开启时，助手自动恢复重启或页面重新加载后丢失的背景；用户主动关闭时不恢复。
- 主窗口匹配允许 URL 查询参数或片段变化。

## 验证

- 已在新版独立测试窗口中验证原粒子渲染器成功运行，界面透明度和清晰模式有效。
- 宇宙渲染器、照片解码和视频播放均在新版实际窗口中验证成功。
- 新版包含头像悬浮层等多个 app 页面，目标选择优先主窗口，避免将背景安装到悬浮层。
- 已完成双架构构建、菜单自检、签名验证和压缩包完整性检查；3.3 已安装。
- 保留已有背景模式、透明度和清晰设置。
- 需要重启主应用时应由用户确认，避免中断其他运行中的任务。

## 后续确认

- 用户重启后主窗口连接已恢复；后续发现的遮挡属于新版颜色变量问题，详见 issue-opaque-panels.md。
- 3.4 已在当前主窗口验证自动恢复渲染层，无需再次重启主应用。
