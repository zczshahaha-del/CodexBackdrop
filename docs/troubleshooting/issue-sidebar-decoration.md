# 侧栏深色竖条遮住聊天文字

主要问题记录：[GitHub Issue #3](https://github.com/zczshahaha-del/CodexBackdrop/issues/3)。原聊天场景仍待用户验收，Issue 保持开放。

## 现象与原因

- 用户截图显示侧栏旁的深色竖条盖住正文左侧文字。
- Codex 的 `.app-shell-left-panel::after` 向侧栏右侧延伸 20 CSS 像素，原本继承透明底色。
- 背景助手给侧栏设置了深色透明底色，装饰层跟随继承。因侧栏层级在正文之上，该层会给靠左的正文加遮罩。
- 在实际窗口对比：启用背景样式时装饰底色为 `rgba(5, 9, 23, 0.792)`；暂时停用样式时恢复为完全透明，几何范围不变。

## 修复

- 明确将侧栏延伸装饰的背景设为透明，侧栏本身继续随滑杆调整。
- 仅覆盖装饰底色，不改正文位置、侧栏宽度、拖动手柄或交互层级。
- 共用背景样式，因此轻量效果、粒子、照片和视频均使用同一修复。

## 验证

- 在实际窗口验证装饰透明且不截获点击；集成测试增加该项检查。
- 修改前新增断言失败，修改后四种轻量效果、粒子和照片切换均通过；测试后恢复原背景与数值。
- 验证结果与本机安装记录见 `docs/verification.md`。
