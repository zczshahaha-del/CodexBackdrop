# 新版深色面板挡住背景

## 原因

- 3.3 虽已恢复调试连接，但只覆盖了旧版 app 颜色变量。
- 新版 `--color-surface`、聊天面板和内嵌消息容器仍为不透明深色。
- 外层和内层同时添加遮罩，产生重复暗化。
- 粒子前景层原先放在界面上方，遮挡面板问题容易被粒子可见掩盖。

## 修复

- 补充现代面板颜色变量，让它们跟随现有滑杆。
- 聊天容器、页面底层和外层壳透明化，只保留主内容区与侧边栏各自的调节层。
- 将粒子和星轨移入背景容器，位于全部内容后方。
- 提高输入框占位提示的可读性。

## 验收

- 已在当前主窗口确认：聊天容器为 `rgba(0,0,0,0)`，原固定不透明底层已移除。
- 20% 时现代面板颜色 alpha 为 0.650，95% 时为 0.040，说明滑杆确实控制新版颜色。
- 已验证照片显示、视频播放和背景模式恢复。
- 已通过前后截图确认：蓝紫色渐变透过主内容区与侧边栏，特效位于内容后方。
- 3.4 已安装并验证自动恢复：临时移除渲染层后，6 秒内恢复当前模式和最新滑杆值。
- 自动恢复计时器使用 common run loop mode，菜单展开时也可工作。
