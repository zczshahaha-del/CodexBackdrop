# 项目需求

- 项目名称：CodexBackdrop
- 当前版本：3.5.3
- 更新日期：2026-10-12

## 用途和用户

为 macOS Codex 用户提供菜单栏可控制的动态背景、照片和视频背景，方便个人使用与分享项目源码。

## 当前范围

- 6 种内置动态效果，其中 4 种轻量效果。
- 照片、视频、透明度与清晰模式。
- 菜单栏启动、设置保存、连接修复和效果恢复。
- 应用背景不退出或重启正在运行的 Codex；连接未开启时保存最后选择，恢复连接后再应用。
- Apple Silicon 与 Intel 通用构建，最低 macOS 13。
- 独立项目目录、GitHub 源码仓库和可重复构建脚本。

## 不在当前范围

- Windows、Linux、云端媒体同步、账号体系。
- 修改 Codex 安装文件或对 Codex 版本变化作兼容保证。
- 自动更新服务、Apple 开发者签名、公证和 App Store 发布。

## 验收

- 构建成功，应用信息、签名和 ZIP 完整性检查通过。
- 新效果显示和切换正常，没有遗留绘制层。
- 透明度与清晰模式保持，效果恢复逻辑正常。
- Codex 运行中未连接时不启动重复实例；关闭背景取消等待，正常启动连接失败后可重试。
- 仓库不包含用户媒体、截图、真实密钥或本机配置。

## 风险

本项目依赖 Codex 内置运行环境、远程调试连接和界面样式。Codex 更新后可能需要重新开启连接或适配。实时绘制的旧宇宙效果开销较大，默认推荐流动渐变。
